# REWARDVERSE Flutter Starter

This is the first UI prototype for REWARDVERSE.

## Included
- Home, Earn, Partners, Wallet, and Profile screens
- Sample coin balance and sample transaction history
- Proposed partner list clearly marked as Planned
- No real payments, surveys, offerwalls, accounts, or withdrawals

## Run
1. Install Flutter SDK and Android Studio.
2. In this folder run: `flutter pub get`
3. Connect an Android device or start an emulator.
4. Run: `flutter run`
